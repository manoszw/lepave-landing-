# Le Pavé Digital — Landing

Landing page commerciale publique pour Le Pavé Digital (audit IA factures transport TPE/PME).

## Déploiement Coolify

1. Pousser ce repo sur GitHub (public).
2. Dans Coolify : **Add Resource → Public Repository → coller l'URL du repo**.
3. Build pack : **Dockerfile**.
4. Domaine (FQDN) : `https://lepavedigital.fr` + `https://www.lepavedigital.fr`.
5. Déployer. Coolify provisionne le certificat Let's Encrypt automatiquement.

## Modifier le contenu

Éditer `index.html` puis push sur GitHub → Coolify redéploie automatiquement.

## Placeholders à remplir

- `[TÉL À COMPLÉTER]` dans le footer
- `[LINKEDIN À COMPLÉTER]` dans le footer
- URL Calendly : créer un calendar `calendly.com/lepavedigital/demo-15min` (slug 15 min)
